# Muhurtham Events — Demo Site

A concept landing page built for a Tamil Nadu wedding planning business.

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Cinematic hero entrance animation with gold rule reveal
- Gold marquee strip
- Scroll-triggered about section with opposition slide
- Service cards with image backgrounds and hover effects
- Masonry gallery with gold border hover
- Animated testimonial quote reveal
- Dark form with emerald focus states
- LERP custom cursor
- Scroll progress indicator
- ScratchStart watermark

## Purpose
This is a concept demo built to showcase frontend animation capabilities to potential clients. Not a real business.
